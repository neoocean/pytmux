pytmux 사용 가이드

설치부터 패널·탭·마우스·메뉴·명령·Claude 연동·토큰·원격·운영·설정·플러그인까지, pytmux 의 모든 기능을 실제 화면 스크린샷과 함께 챕터별로 안내합니다. 각 페이지 아래에는 이전·다음 챕터로 이어지는 링크가 있습니다. 처음이라면 1. 시작 · 핵심 개념부터 차례로 읽으세요. 빠르게 둘러보려면 랜딩 페이지를 먼저 보세요.

🛠 최근 수정사항 · 2026-10-02 금요일 전체 변경 내역 →
  • Claude Claude Code 가 이제 스스로 하는 일 넷을 pytmux 에서 걷었습니다. Claude Code 는 사용량 한도가 풀리면 열린 세션을 스스로 이어 가고(2.1.234~), 대화형 세션을 auto 권한 모드로 시작합니다(2.1.284~). 시작 규칙·피드백 문구·원격 제어 자동 연결도 자기 설정으로 다룹니다. 겹친 채 두면 서로 방해합니다 — 예를 들어 pytmux 가 한도 리셋 시각에 대신 치던 continue 가 Claude Code 의 대기를 끊어 버립니다. 그래서 다음을 없앴고, 각각 대신 쓸 설정을 가이드에 적었습니다.
    • 토큰리밋 자동 재개(prefix R·상태줄 AR·auto-resume) → Claude Code 의 「Continue automatically at usage limit」(기본 켜짐)
    • auto-launch·claude-auto-mode → 기본 auto 모드 · "remoteControlAtStartup": true
    • claude-rules → SessionStart 훅(적어 두었던 규칙은 상태 디렉터리의 …claude-rules.retired.txt 로 한 번 보존됩니다)
    • claude-disable-feedback 플러그인 → "spinnerTipsEnabled": false · "feedbackSurveyRate": 0
    전송 오류 자동 재시도(auto-retry)는 그대로입니다 — Claude Code 는 재시도를 다 쓰면 대화형 턴을 끝내기 때문입니다. 파이썬·GUI 클라이언트 둘 다에 적용됩니다. 자세한 설정은 8. Claude Code 연동.
  • 토큰 토큰 사용량 판에서 Tab·←→ 로 탭을 오가고, [머신] 탭이 기기 이름을 씁니다. 지금까지는 판 안에서 다른 탭으로 가는 길이 클릭과 글자 바로 가기(p·l·o)뿐이었습니다. Tab 은 판을 닫아 버렸고 ←→ 도 세션·머신 탭에서는 판을 닫았습니다(GUI 는 두 키를 삼켰습니다).
    • Tab·Shift+Tab — 언제나 다음·이전 탭으로 옮기고 끝에서 감깁니다. 판은 닫히지 않습니다.
    • ←→ — 그 줄에 다른 뜻이 없을 때 이웃 탭입니다. 기간 트리의 펼침·접힘과 한도 탭 모델·컨텍스트 줄의 값 고르기는 그대로입니다.
    • [머신] 탭 · 요약줄 Σ 분해 · GUI 의 머신 판이 같은 이름을 씁니다 — 등록할 때 붙인 기기 이름(보통 호스트 이름)이고, 동기화 서버가 아직 이름을 내려 주지 않으면 셋 다 기기 id 앞 8자리입니다. 종전에는 같은 기기를 세 자리에서 12자 · 8자 · 32자 전체로 다르게 적었습니다.
    • GUI 판은 탭을 옮겨도 높이가 그대로입니다 — 내용이 짧은 탭으로 가면 판이 줄어들던 것을 고쳤습니다.
    파이썬·GUI 클라이언트가 같은 규칙을 씁니다. 자세한 것은 9. 토큰 사용량.
  • 블록 위로 굴리면 패널 첫 줄에 지금 보는 출력의 명령이 붙고, 블록 요약 판이 파이썬 클라이언트에도 생겼습니다. 긴 출력 한가운데서 「이게 무슨 명령의 출력이었지」를 찾으러 다시 위로 굴릴 필요가 없습니다.
    • 스티키 프롬프트 바 — 굴린 패널 첫 줄에 ▲ 명령 띠가 붙고(Claude 패널이면 그 답을 끌어낸 프롬프트), 띠를 누르면 그 프롬프트 줄로 건너뜁니다. 파이썬·GUI 클라이언트에 같은 날 들어갔고, 어느 줄에 띠를 세울지는 한 벌의 규칙을 같은 사례 표로 맞대어 잽니다.
    • 블록 요약 판(summary) — 활성 패널의 블록을 결과 표식(ok·err 등) · 명령 · 작업 디렉토리로 한 판에 보여 줍니다. GUI 에만 있던 판입니다.
    • 그 맞대기가 기존 결함을 하나 잡았습니다 — 파이썬 클라이언트에서 블록을 고르면 다음 명령의 프롬프트 줄까지 한 줄이 딸려 강조·복사되던 것을 고쳤습니다.
    • 알려진 문제 — 파이썬 클라이언트에서 띠의 명령 글자가 파일 경로처럼 보이면 그 글자를 눌렀을 때 스크롤 대신 경로가 복사됩니다. 고칠 때까지는 띠의 빈 자리를 누르세요.
    셸 블록은 셸 통합 설정이 있어야 생깁니다 — blocks 플러그인.
  • GUI GUI 의 스크롤바를 끌 수 있고, RTT 그래프가 실제 값으로 그려지며, 알림 이력 판이 정본처럼 움직입니다.
    • 스크롤바 — 보이기만 하던 오른쪽 막대를 잡아 끌어 스크롤하고, 막대 바깥 트랙을 누르면 그 비율 자리로 건너뜁니다.
    • RTT 그래프 — 글자 칸을 8단계로 칠하던 막대를 실제 값에 비례하는 픽셀 막대로 바꿨습니다. 임계는 점선, 측정이 없던 구간은 바닥의 점입니다.
    • 알림 이력 판 — 커서로 고르고 Enter 로 전문을 펼치고 c 로 복사합니다. 꼬리줄 안내도 「아무 키나 닫기」에서 실제 키(↑↓ · Enter · c · Esc)로 바꿨습니다.
    • 상태 판의 PageUp·PageDown 이 정본처럼 5줄씩 움직입니다.
    이로써 두 클라이언트가 다르게 구는 자리를 적어 두는 목록(갈림 대장)의 「할 일」이 0 이 됐습니다 — 남은 갈림은 터미널이 못 주는 키 · 픽셀 그림 · OS 창 통합뿐입니다. GUI 클라이언트 소개.
