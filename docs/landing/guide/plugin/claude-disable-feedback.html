claude-disable-feedback

이 플러그인은 없앴습니다(2026-10-01). Claude Code 가 같은 일을 설정으로 하게 됐기 때문입니다.

대신 이렇게 끕니다

~/.claude/settings.json 에 두 줄을 적습니다.

{
  "spinnerTipsEnabled": false,
  "feedbackSurveyRate": 0
}
  • spinnerTipsEnabled — 시작·작업 중 팁(Use /feedback to help us improve! 포함)을 모두 끕니다.
  • feedbackSurveyRate — 세션 평가 배너(How is Claude doing this session?)를 끕니다. 환경 변수 CLAUDE_CODE_DISABLE_FEEDBACK_SURVEY=1 로도 됩니다.

왜 없앴나

이 플러그인은 문구를 글자 그대로 찾아 화면에서 공백으로 덮었습니다. Claude Code 가 문구를 조금만 바꿔도 조용히 안 먹는 방식이라, 설정이 생긴 뒤로는 둘 이유가 없었습니다. ← 플러그인 개요
