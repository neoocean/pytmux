플러그인 · Claude

claude-token-usage-view

Claude 사용 한도(세션 5h·주간)를 막대로, 다음 리셋까지 남은 시간을 큰 블록 숫자로 보여줍니다. 기본은 팝업이고, 풀스크린 화면이나 패널 오버레이로도 띄울 수 있어 상시 모니터에 적합합니다.

여는 법

명령설명
usage-view한도+카운트다운 화면 (usage-view [popup|tab|pane], 기본 popup; 별칭 token-viewer·usage-clock)
usage-view popupclaude-code 플러그인이 있으면 claude-token-log 팝업을 한도 탭으로 엽니다. 없을 때만 전용 팝업 화면으로 대신합니다
usage-view tab클라이언트 풀스크린 화면 — pytmux 탭(서버 탭)이 아니라 이 클라이언트 창을 덮는 화면입니다
usage-view pane현재 패널을 한도 막대 + 카운트다운으로 덮는 오버레이(같은 명령을 다시 치면 닫힘)

메모

한도 값은 claude-code 플러그인의 실측(/usage) 데이터를 같이 씁니다. tab 은 화면 전체를, pane 은 패널 하나를 차지하는 대시보드가 됩니다.

끄기 · 제거

:plugins 관리 팝업에서 끄거나(가역), pytmuxlib/plugins/claude-token-usage-view/ 디렉토리를 지우면(delete-to-disable) 명령·자동완성·메뉴 어디에도 나타나지 않고 조용히 사라집니다. 코어는 영향받지 않습니다. ← 플러그인 개요
